# Навыки дизайна для этого репозитория

Установлены полные копии трёх навыков. Они хранятся вместе с проектом и попадают
в облачную задачу при выборе ветки, содержащей эти файлы. Локальная установка
на личном компьютере для этого не нужна.

| Навык | Для чего | Оригинал |
| --- | --- | --- |
| `emil-design-eng` | Детали интерфейса, компоненты, доступность и качество анимаций | [Emil Kowalski](https://github.com/emilkowalski/skills/tree/715c1807e08c497cfd1dc4feb450a2a3300ef2a9/skills/emil-design-eng) |
| `animate` | Создание осмысленных анимаций и переходов | [Emil Kowalski](https://github.com/emilkowalski/skills/tree/715c1807e08c497cfd1dc4feb450a2a3300ef2a9/skills/animate) |
| `design-taste-frontend` | Композиция и визуальный дизайн страниц; Taste Skill 2.5.1 | [Taste Skill](https://github.com/Leonxlnx/taste-skill/tree/f6b76575f949707b4e3c37cd86cb44b0b98643e8/skills/taste-skill) |

У Taste название исходной папки — `skills/taste-skill`, а поле `name` в `SKILL.md`
и имя для вызова — `design-taste-frontend`. Здесь папка названа по этому полю.
Включены все 1631 файл Taste: инструкции, скрипты, справочники, шаблоны,
изображения и прочие ресурсы. Это примерно 36,6 МБ, которые не подключены к сайту.
У Emil включены `SKILL.md` обоих навыков и `animate/RECIPES.md`.
В каждую папку добавлена неизменённая корневая MIT-лицензия соответствующего автора;
отдельные лицензии и атрибуции ресурсов Taste также сохранены.

## Использование в Codex Cloud

После слияния PR начните новую задачу на обновлённой `main`; до слияния можно
выбрать ветку `codex/install-design-skills`.

Codex поддерживает навыки проекта в `.agents/skills/` по
[официальной документации](https://learn.chatgpt.com/docs/build-skills).
[Облачная среда](https://learn.chatgpt.com/docs/environments/cloud-environment)
получает выбранную ветку и читает корневой `AGENTS.md`. В нём есть явные пути:
агент сможет прочитать инструкции и в среде без автоматического списка навыков.

Пример задачи:

> Используй design-taste-frontend и emil-design-eng из .agents/skills.
> Улучши первый экран сайта: композицию, типографику и мобильную версию.
> Сохрани мои фотографии, тексты, цены и ссылки. Для изменений анимации используй
> animate. Проверь результат на телефоне и компьютере и перечисли ограничения проверки.

Для проверки установки без изменения сайта:

> Прочитай AGENTS.md. Найди три SKILL.md в .agents/skills, перечисли их имена
> и назначение. Проверь наличие Node.js 22+ и Chrome/Chromium. Ничего не изменяй
> и не запускай сторонние скрипты.

## Требования и пределы проверки

- Инструкции Emil — Markdown, дополнительная установка для чтения не нужна.
  В них упоминаются другие навыки автора, например `pick-ui-library` и
  `review-animations`; они не входят в эту установку. Если такой навык нужен,
  не утверждайте, что он уже установлен.
- Taste использует Node.js 22+ и установленный Chrome, Edge или Chromium.
  Для нестандартного расположения браузера задаётся `CHROME_PATH` в настройках
  облачной среды. `ffmpeg` нужен только для отдельных преобразований изображений.
  Это инструменты разработки, а не зависимости самого сайта.
- Перед первой браузерной проверкой проверьте запуск браузера в конкретном
  контейнере. Наличие браузера, разрешения и его настройки зависят от среды;
  по одной установке файлов нельзя подтвердить успешную работу проверок.
- Чтение локальных инструкций и использование включённых ресурсов не требуют
  интернета. Загрузка дополнительных фото, иконок и Google Fonts требует
  разрешённого сетевого доступа; API-ключи для самих навыков не нужны.
- В исходном `SKILL.md` Taste сохранён блок `hooks.Stop` для Claude Code.
  Эта установка не регистрирует его в Codex. Автоматическая проверка по завершении
  задачи не гарантируется: в Codex проверку нужно запускать явно после проверки
  кода скрипта. Корневые установщики и конфигурации плагинов авторских репозиториев
  не установлены.
- Во время установки сторонние скрипты, браузерные проверки и hooks не запускались.
  Выполнены сверка файлов с зафиксированными оригиналами и статическая проверка
  структуры. Фактическая облачная сессия пользователя отсюда не запускалась.

## Версии и обновление

Точные коммиты и исходные папки записаны в `sources.json`. Все файлы внутри
исходных папок скопированы без изменений. Обновления не выполняются автоматически.

Для обновления создавайте отдельную ветку: прочитайте изменения у автора,
выберите конкретный коммит, замените полную папку соответствующего навыка,
сохраните лицензии и обновите `sources.json`. Проверьте имена в `SKILL.md`,
относительные ссылки и отличия от предыдущей версии. Не запускайте автоматически
команды `npx ...`, `install.sh` или новые скрипты из обновления.

Официальные инструкции авторов:
[Emil](https://github.com/emilkowalski/skills/blob/715c1807e08c497cfd1dc4feb450a2a3300ef2a9/README.md),
[Taste](https://github.com/Leonxlnx/taste-skill/blob/f6b76575f949707b4e3c37cd86cb44b0b98643e8/README.md).
