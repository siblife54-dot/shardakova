# Указания для Codex

## Проект

Это статический лендинг на HTML, CSS и обычном JavaScript; запуск и проверки описаны
в `README.md`. Сохраняй текущий стек без сборки и зависимостей, если задача не требует
его изменения.

## Навыки для дизайна

Перед работой над интерфейсом прочитай подходящий файл целиком. Пути относительно
корня репозитория; это также способ использовать навыки в облачной среде, если она
не показывает их в списке навыков:

- Создание страницы, редизайн и визуальная композиция:
  `.agents/skills/design-taste-frontend/SKILL.md`.
- Качество компонентов, состояния, доступность и детали интерфейса:
  `.agents/skills/emil-design-eng/SKILL.md`.
- Создание или изменение анимации:
  `.agents/skills/animate/SKILL.md`; при необходимости также `RECIPES.md` рядом.

Открывай дополнительные материалы выбранного навыка по мере необходимости.
Для задач, не связанных с интерфейсом, эти навыки не обязательны.

## Применение к этому сайту

- Задача пользователя и правила проекта определяют объём изменений. Примеры,
  палитры и шаблоны навыков адаптируй к существующему сайту. Локальная правка
  не должна превращаться в полный редизайн или замену страницы на starter.
- Сохраняй подтверждённые тексты, цены, фотографии, контакты, ссылки оплаты,
  домен и поведение сайта, если задача не предусматривает их изменения.
  Не заменяй реальные данные примерами или адресами `.example` и не выдумывай факты.
- Если рекомендации навыков расходятся, приоритет у требований пользователя,
  доступности, читаемости на телефоне и скорости. Taste используй для композиции,
  Emil — для деталей и осмысленного движения; декоративная анимация не обязательна.
  Сохраняй поддержку `prefers-reduced-motion` и клавиатуры.
- Сторонние файлы в `.agents/skills/` — инструменты разработки. Не подключай весь
  набор к странице автоматически; переноси в сайт только необходимые ресурсы
  в рамках конкретной задачи и сохраняй их лицензии и указание авторства.
- До запуска стороннего скрипта прочитай его и проверь вызываемые команды,
  сетевые обращения и пути записи/удаления. Для браузерных проверок Taste нужны
  Node.js 22+ и Chrome/Chromium; используй отдельный временный профиль.
  Не запускай установщики и не включай автоматические hooks только ради чтения навыка.
- При изменении интерфейса выполняй проверки из `README.md`. Проверки Taste
  запускай явно после проверки их кода и наличия нужных инструментов. Если
  проверка недоступна, сообщи, что именно не проверено; не выдавай это за PASS.
  Наличие навыков само по себе не требует запуска сайта или его изменения.
